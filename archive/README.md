# Archive

Historical documents kept for reference. Nothing here describes the current
language or is used by the code or tests.

- `IDEA.md`, `MIGRATION.md`, `SYNAPSE_BRIDGE.md`: the original idea and the
  rename from the Synapse codename.
- `IMPLEMENTATION_SUMMARY.md`, `CLOUD_EXECUTION_DESIGN.md`,
  `ENGINE_ENHANCEMENT_DESIGN.md`: exploratory cloud and engine designs that were
  not built into the supported product.
- `KILOCODE_PROMPT.md`, `astra-prompt-*.md`: prompts written for other coding
  assistants.
- `generated/`: rendered output of the Maya city example.

Current documents live in the repository root: `README.md`, `TUTORIAL.md`,
`AGENT_GUIDE.md`, `KOSIKA.md`, and `KOSIKA_PLAN.md`.
