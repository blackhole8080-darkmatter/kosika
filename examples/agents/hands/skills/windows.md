# How to act in a Windows program
When: window, button, menu, click, press, notepad, calculator

Look before acting: `look` lists the things a window has, by their names.
Press a thing by the name `look` gave, with `press`, so your own pointer
moves and the person's mouse stays where they left it. Use `click` and
`move` only when the thing has no name to press by. One action at a time:
the person says yes to each, and holding Escape stops you at once.
