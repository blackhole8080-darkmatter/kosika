# How a note is written in Notepad
When: note, notepad, write, jot
Files: *.txt

Open Notepad with the `open:notepad` hand, then write with the `write` hand
so your own pointer shows where the words go. Write the note as the person
said it; do not add a title, a date or a sign-off they did not ask for.
After writing, say what the check said: the words are there, or they are not.
Never say a note was written if the check did not find it.
