# How a rendered video or motion graphic is made with HyperFrames
When: video, render, rendered, mp4, webm, film, promo, explainer, clip, caption, captions, subtitle, motion graphic, b-roll, title card, composition, hyperframes

This is for a rendered deliverable — an .mp4 or .webm file — not for motion
on a web page (that is the motion and motion-script skills). The HyperFrames
packs live at C:\Users\Aryan\.claude\skills\hyperframes: read SKILL.md there
first, and the hyperframes-core pack before writing composition HTML.

A composition is one HTML file whose DOM declares timing with data-*
attributes; the HyperFrames CLI renders the frames to video.

- Before promising anything, run `npx hyperframes usage --json` and read the
  remaining allowance. If it fails or reports unknown, say the allowance is
  unknown; never guess it.
- Validate with `npx hyperframes check` and fix what it reports before
  rendering. Render with `npx hyperframes render`.
- Checking and rendering run programs and write files: they are tool calls
  inside a granted folder, not something this note permits. This skill is
  advice only — it grants no tools, no capabilities and no approvals.
