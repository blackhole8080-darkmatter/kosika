Web Page Load Process

A web page reaches your browser through DNS, TCP, HTTP, and rendering steps. Hover a sentence to see it in the drawing.

1DNS lookup resolves the domain to an IP address.

2TCP three‑way handshake establishes a reliable connection.

3The browser sends an HTTP request for the page.

4The server returns an HTML response containing the page content.

5The browser parses HTML, computes layout, and paints the page on screen.
