Quick preview — what you write

record Question {
  text: Text
}
record Answer {
  text: Text
  confidence: Number
}

model writer {
  input: Question
  output: Answer
}

workflow answer(question: Question) -> Answer {
  step respond {
    let result: Answer = use_model writer(text: question.text)
    return result
  }
}

What Kosika is meant to do

For developers building AI

Make AI easy to build, simple to read, and powerful to run — regardless of which model you use. Declarative structure. Typed boundaries. Reusable agents. Explainable code.

  • One language for models, tools, agents, and workflows
  • Works with any OpenAI-compatible model — local or cloud
  • Connect any MCP server — pinned, validated manifests
  • Typed records and tool inputs — schemas everywhere
  • Deterministic mindmaps and diagrams — no guessing
  • Replayable traces — run, replay, debug offline
  • Approval pauses for durable mutations — human-in-the-loop
  • Parallel read-only DAGs for batched research
  • Capability-secure — tools declare observe/execute
  • Pure functions — deterministic
