What it is

A program you can interrogate.

Most agent tools ask for trust. Kosika is built to be checked: the language, the runtime, and Studio all carry the same rule — show the work. Four things make that real:

Checked, not trusted

Every program is read by the checker before it runs. A program that does not check does not start. A model can propose; only a checked program executes.

Granted, never ambient

Files, web, other programs — every tool is a grant you gave, and agents ask your yes before anything changes. Nothing is assumed.

Recorded, always replayable

Every run leaves a trace: each model call, each tool, each second. Replay is free and asks no model — press play on the past.

Bounded by real numbers

Runs carry budgets — steps, seconds, money. When the budget ends, the run ends. No surprises on the bill.

How it works

Fifteen minutes, no programming required.

You do not need to know how to program to use Kosika, and you do not need the internet once it is installed.

Write it — or take one

Agents are short programs in the Kosika language, and three starter agents come with the install. In Studio, every part of a program is a card you can open and read.

The checker reads it first

Before anything runs, the checker reads the whole program: names, types, grants. If something is wrong it says so in words — it cannot run, and here is why.

Run it, and watch

Run with the model you already have — or with none at all. Every step lands in the trace: what was asked, what was used, what it cost, what it changed.

Start

  
Three commands.

  

    

      
python -m pip install .click to copy

      
kosika startclick to copy

      
ollama pull qwen2.5:7bclick to copy

    

    

      
One command does the work. kosika start makes an agents folder in your home directory with three starter agents, looks for a model already on your computer, and opens Studio.

      
It tells you what it found — and it grants nothing: no agent can read your files, start programs or reach the web until you say so.

      
No model yet? Studio still opens, every agent can be read and tested, and runs can be replayed. The simplest model is a local one: install Ollama and pull qwen2.5:7b — about 5 GB of disk, nothing leaves the machine.

    

  







  
Questions

  
Asked honestly.

  

    
Is it calling a model right now?
Only if you granted one, and you can see every call: the exact words sent and returned are in the trace. Replay never calls a model — the film above is a recording, played by your scroll.

    
Where does my data go?
Nowhere. Kosika and Studio run on your machine; agents, traces and memories are files in your folder. There is no account, no telemetry, no cloud.

    
Why a language, and not another framework?
Frameworks hide the machine under abstractions. A small language can be checked: the program you read is the program that runs, and the checker can prove things about it before a single step happens. That is what makes "show the work" a guarantee rather than a promise.

    
What if the model makes a mistake?
Then the mistake is visible, bounded and recorded — and precise work is done by exact code, not by the model. The model proposes; checked programs execute; budgets cap the damage.

    
Can I use it without programming?
Yes. The getting-started tour takes about fifteen minutes, needs no programming knowledge, and the starter agents already do useful things — reading, reminding, answering.
