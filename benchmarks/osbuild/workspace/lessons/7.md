Title: Interrupts and a timer
Guide: 18-interrupts, 19-interrupts-irqs, 20-interrupts-timer

Snapshots: 2
Expect: MayaOS timer
Rising: Ticks:
---
Building on stage 6, set up the IDT with the 32 CPU exception handlers and the 16 IRQ
handlers (remap the PIC so IRQs come at 32 to 47), each going through one assembly stub to a
C handler, and enable interrupts. Program the PIT (port 0x40/0x43) for 50 Hz. main prints
"MayaOS timer" on the first row, and the timer interrupt handler rewrites the start of row 3
with "Ticks: N", where N is the number of timer interrupts so far. The screen is read twice,
a second apart, and N must have grown.
