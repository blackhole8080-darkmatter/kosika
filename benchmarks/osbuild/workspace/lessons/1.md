Title: A boot sector that greets
Guide: 01-bootsector-barebones, 02-bootsector-print
Keys:
Snapshots: 1
Expect: MayaOS boot
---
Write a 512-byte boot sector in NASM (boot.asm, assembled with `nasm -f bin`) that the BIOS
loads at 0x7c00. It prints the text "MayaOS boot" with the BIOS teletype call (int 0x10,
ah 0x0e), one character at a time from a string in memory ending with a zero byte, then
loops forever. It must end with the boot signature 0xaa55. The Makefile's os-image.bin is
the boot sector itself.
