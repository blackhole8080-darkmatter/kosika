Title: Into 32-bit protected mode
Guide: 08-32bit-print, 09-32bit-gdt, 10-32bit-enter
Keys:
Snapshots: 1
Expect: Real mode: MayaOS starting
Expect: Protected mode: MayaOS is 32-bit
---
In 16-bit real mode the boot sector prints "Real mode: MayaOS starting" with the BIOS.
Then it defines a flat GDT (null, code and data segments), disables interrupts, loads the
GDT, sets the PE bit of cr0, and far-jumps to 32-bit code. In 32-bit mode it sets the data
segment registers and a stack, and writes "Protected mode: MayaOS is 32-bit" straight to
video memory (0xb8000, white on black) at the start of row 5, then loops forever.
