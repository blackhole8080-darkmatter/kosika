Expect: MayaOS shell

---
Building on stage 7, add a keyboard driver on IRQ1 that reads scancodes from port 0x60 and
turns letters, space, backspace and Enter into characters (upper case is fine), echoing
them. main prints "MayaOS shell" and a prompt "> ". When Enter is pressed, the typed line is
handled: "END" prints "Bye from MayaOS" and halts the CPU; anything else prints
"You said: " and the line, then a new prompt. The test types "maya", Enter, "end", Enter.
