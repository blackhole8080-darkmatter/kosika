Title: A kernel written in C

---
A boot sector (boot.asm) loads a kernel from the disk to 0x1000 while in real mode, enters
32-bit protected mode, and calls it. The kernel is C (kernel.c) with a small assembly entry
(kernel_entry.asm, `[bits 32] [extern main] call main` then `jmp $`, assembled with
`nasm -f elf`). kernel.c's main writes "MayaOS kernel is running" to video memory at the
top-left of the screen, white on black, character by character through a char pointer to
0xb8000. Link kernel_entry.o first. os-image.bin is the boot sector followed by the kernel
binary, padded so the boot sector's read of enough sectors (at least 16) cannot fail.
