The os-tutorial's own code for lesson 02-bootsector-print (Carlos Fenollosa, BSD 3-Clause).
It uses i386-elf-gcc and i386-elf-ld; use the commands in your rules instead.

=== boot_sect_hello.asm ===
mov ah, 0x0e ; tty mode
mov al, 'H'
int 0x10
mov al, 'e'
int 0x10
mov al, 'l'
int 0x10
int 0x10 ; 'l' is still on al, remember?
mov al, 'o'
int 0x10

jmp $ ; jump to current address = infinite loop

; padding and magic number
times 510 - ($-$$) db 0
dw 0xaa55
