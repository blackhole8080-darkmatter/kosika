# Programs outside the suite that the engines do not yet agree on.
#
# `python -m kosika.conformance agree ENGINE` checks every other .kos in the
# repository: both engines must give it the same verdict, and run its tests
# with the same result. A program here is held to what its line says:
#
#   engine-cannot PATH  the reference checks it; the other engine refuses it
#                       by name ("kosika-native cannot ... yet"), never with a
#                       syntax error or a crash
#   checks-nowhere PATH neither engine checks it: an example written in syntax
#                       Kosika does not have, waiting to be rewritten
#
# The list only shrinks. A program listed here that the engines now agree on
# fails the gate until its line is taken out, so a fix is never forgotten.
